# CA difftest corpus inventory — `audit/DIFFTEST_CA_INVENTORY.md`

Summary of the 43 CA corpus hex files (86 files including their `.meta.json` siblings, plus
the `README.md` = 87 non-hex entries) in
[`difftest/corpora/confidential_assets/`](../difftest/corpora/confidential_assets/).

These are VM-generated byte-level goldens that every CA corpus row compares against. Each hex
file pairs with a `.meta.json` describing the generation context (inputs, expected VM output,
natives touched). Categorized below by what they test.

### 3. Sigma deserialization — single-verifier shapes (2 files)

`deserialize_sigma_transfer_26_scalars_30_points.hex` (1792 B); each `_plus_<N>_auditor_quads`

auditor-count-sensitive bug.

### 5. Auditor-amount serialization (8 files)

Tests that `serialize_auditor_amounts` encodes varying (actual, pending) balance pairs
correctly under distinct auditor counts / orderings:

| File | Shape |
|---|---|
| `serialize_auditor_amounts_one_zero_pending.hex` | 1 auditor, zero pending |
| `serialize_auditor_amounts_two_zero_pending.hex` | 2 auditors, both zero pending |
| `serialize_auditor_amounts_one_u64_one_pending.hex` | 1 auditor, u64::MAX pending |
| `serialize_auditor_amounts_one_actual_zero.hex` | 1 auditor, actual=0 |
| `serialize_auditor_amounts_zero_then_u64_one_pending.hex` | 2 auditors: (0, u64::MAX) |

| `serialize_auditor_amounts_u64_one_then_zero_pending.hex` | 2 auditors, yet another permutation |

The sibling orderings directly catch auditor-order-sensitive bugs in the serializer.

## How to regenerate

Each file is produced by running the corresponding Move VM harness in
`difftest/move/` and dumping the byte-level output. See
[`difftest/README.md`](../difftest/README.md) for the regeneration command.

## How to consume

Lean tests reference these files via the `Runner` corpus mapping at
`lean/MovementFormal/Experimental/ConfidentialAsset/RegistrationDifftestOracle.lean` (and
similar per-operation mappings). Each Lean row pairs a corpus `.hex` with the Lean side's
computed byte sequence; `lake build MovementFormal.…DiffTestBridge` cross-checks them.

CI job that validates all 87 rows agree: `.github/workflows/formal-difftest.yaml` (`lean-proofs`
job, step "difftest corpora").
